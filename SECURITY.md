# Security

This is pre-release software. Do not publish secrets or private conversation data in issue reports. No maintainer security address has been supplied; arrange a private reporting channel before any public release.

Treat model output, source pages, tools and imports as untrusted. No model-output execution exists. Keys are memory-only; normal exports exclude them. Backups are plaintext and can contain private text and attachments. Remote endpoints receive submitted data. Native downloads require folder selection and never intentionally overwrite existing models. Native security review and cross-platform testing are pending; do not treat this checkpoint as hardened.
